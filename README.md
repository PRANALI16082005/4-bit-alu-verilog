# 4-bit Arithmetic Logic Unit (ALU)

Designed a 4-bit Arithmetic Logic Unit (ALU) using Verilog HDL as part of VLSI system design learning.

## What it does

The ALU performs arithmetic and logic operations based on the control signal:

- **Arithmetic:** add, subtract, increment, decrement
- **Logic:** AND, OR, NOT, XOR

## Features

1. Performs both Arithmetic and Logic operations.
2. 4-bit input A and B, with Carry-in (Cin) and Mode control (M).
3. Outputs 4-bit result (S) and Carry-out (Cout).
4. Behavioral modeling using case statements.

## How to run in Vivado

1. Open Vivado → Create a new project.
2. Add these two `.v` files (`alu.v` and `tb.v`) under "Sources".
3. Set `tb.v` as the top module.
4. Click Run Simulation → Run Behavioral Simulation.
5. View results in waveform viewer or simulation log.
